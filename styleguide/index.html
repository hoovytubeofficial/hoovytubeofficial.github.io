Rules checklist

  • Same chrome everywhere. The dock, CTA band and footer are injected by ht-nav.js. Never hand-build them.
  • No floating text. Every heading, eyebrow, paragraph, caption, stat and label sits on a panel, plate, chip, button or table. Never put text on the page background or over video/imagery. Section titles go in .section-head.
  • Every page sells Patreon. (a) a Patreon CTA in the first screen/hero, (b) at least two inline a.hl-patreon links, (c) one page-relevant .upsell, (d) the sitewide CTA band (automatic).
  • Patreon Rust is for Patreon only. Never use btn-patreon, panel-patreon, tag-patreon or hl-patreon for anything else.
  • Facts only. Numbers, prices and features come from the research files. No invented ratings, counts, reviews, testimonials or guarantees.
  • Privacy. No real name, age, city or country. No age-revealing lines.
  • Both themes, 390px, zero errors. No horizontal overflow at phone width; motion is subtle and off under reduced motion.

Shape: outline --bw 3px (chips 2px), hard depth edge --depth 6px (buttons 4px, chips 2px), radius --r-lg 18px for panels, --r-md 12px for buttons and tiles, pills for chips and tags. Containers: .container 1160px, .container-narrow 860px, .container-wide 1320px, all with a 16-32px gutter.

Layout

Block rhythm

Blocks stacked straight inside a section's .container are spaced automatically by --flow-gap: one --gap of clear space under every depth edge, the same as between grid rows. Wrap a group anywhere else (a .split column, a <div>) in .flow to get the same rhythm. .split-fill makes two columns end level. Never add your own margins between blocks.

Surfaces

Panels

The glossy die-cut plate. Cream in light, deep slate in dark. Variants: inverted, olive item badge, Patreon (Patreon only), inset. Put .panel on an <a> (or add .is-link) for the hover lift.

Type on plates

Section heads & eyebrows

Section titles never float: they sit on .section-head. Eyebrow chips label what follows.

Actions

Buttons

Glossy die-cut buttons with a pressed state. One .btn-patreon per block at most; it is the money button. External links get target="_blank" rel="noopener".

Emphasis

Highlighted text

<mark class="hl"> is the gold highlighter swipe for key facts. a.hl-patreon is the only way to link to Patreon inside text: bold, Patreon Rust, tinted swipe and a mini Patreon mark. Add .no-icon to drop the mark.

Numbers

Stat tiles

Write the real final value in the HTML. data-count makes it count up once when it scrolls into view (skipped under reduced motion). Inside a panel the tiles turn into inset wells.

Lists

Feature list & check list

Forged icons as bullets (use /assets/icons/forged/*.png, empty alt). .cols-2 splits it into two columns on wide screens.

Media

Media screen

Every video, poster and embed sits in a glossy bezel. Captions go in .screen-cap on the bezel, never over the picture. Videos: always muted loop playsinline preload="none" plus a poster from /media/posters/; data-play="visible" or "hover" handles playback.

Layout

Card grid

.grid auto-fits with --min (default 260px). .grid-2 / .grid-3 / .grid-4 lock the column count on desktop and collapse on small screens. .card is a compact panel with media, title, text and actions.

Layout

Bento

A 6-column mosaic: children take .b-2 / .b-3 / .b-4 / .b-6 and optional .b-tall. Two columns under 900px, one under 600px.

Patreon

Pricing tiers

Real tiers and points only (see patreon.json). .is-featured + .tier-flag marks the best-value tier. Every tier button is .btn-patreon to the membership URL.

Tables

Comparison table

The table scrolls inside its plate on phones (never the page). .yes / .no cells draw the tokens; keep a visually hidden label in each cell. .col-featured tints a column.

How-to

Steps

Numbered die-cut tokens from a CSS counter. Add .steps-row to lay them out side by side.

Answers

FAQ accordion

Native <details>: works without JS. Give every item the same name for one-open-at-a-time (or put data-accordion on the wrapper).

Browse

Filter chips

No page JS needed: name a group, give each chip a data-filter, give each item data-tags. Counts, the live status line and the empty state fill in automatically.

Labels

Tags

Short status labels. .tag-patreon only for things that need a membership or shop purchase.

Persuasion

Callout & upsell

.callout is a panel with an icon (any variant). .upsell is the page-relevant Patreon pitch: plate with a Patreon strip, badge art, copy, and a .btn-patreon. Every page needs one upsell that fits its topic.

Lists

Item card

Icon + title + meta + action. For Workshop items, packs and downloads. .is-compact puts the action on the right. Make the whole card a link with a.item-card (then leave out the button).

Page top

Page hero panel

The first thing in <main> on every page: one panel with eyebrow, h1, lead, a Patreon CTA plus one secondary action, and media on the right. No breadcrumbs. .is-text-only centres it without media.

Info

Notice

A slim plate for requirements and caveats. .notice-warn and .notice-free change the edge colour.

Input

Forms

Inputs are sunken wells inside a plate. Labels use .field. Messages go in .form-msg with .ok / .err. Any element with data-newsletter-open opens the newsletter panel; data-message-open opens the send-a-message modal.

Instructions

Code block

For install steps, file paths and snippets, inside or outside a panel. The bar label says what it is; the Copy button uses data-copy. Add .is-wrap for long paths that should wrap instead of scrolling. Long lines scroll inside the block, never the page.

Media

YouTube embed

Never drop raw iframes on a page. Put a facade link in .screen-media: a poster and the forged play token. On click, ht-ui.js swaps in a youtube-nocookie.com player titled from data-title; nothing loads from YouTube before that. Without JS the link opens the video on YouTube. Write the real video title in data-title and the caption, or leave the title out if it is not confirmed.

Long text

Prose

For journal posts and long explanations: a panel with .prose inside.

Long text

Journal post & post list

A post is a text-only hero plate (eyebrow, title, dek, .meta line with the date and tags, no byline) followed by the .prose panel and the page's upsell. The list is a grid of whole-card links. Split very long posts into several <section>s if you like; reveal works at any height.

Motion

Reveal & count-up

Automatic: every main > section and the CTA band fade and rise in once, as soon as their top edge enters the viewport (any height works, a failsafe catches missed callbacks). Add data-reveal to any other block, or data-reveal="stagger" to reveal a grid's children in turn. Anything already on screen at load is never hidden; reduced motion turns it all off.

Automatic

Dock, CTA band, footer

All injected by /shared/ht-nav.js. You only write <footer class="site"></footer>. Scroll down to see the live Patreon CTA band and footer on this page.

  • Dock: Home, Patreon, Workshop, HoovyTools, Learn, Journal, Contact, then Search and Theme. The current page is marked automatically (/patreon/ also lights Patreon).
  • CTA band: inserted right before footer.site. Opt out only with <body data-no-cta> (for example the styleguide could, but it keeps it for reference).
  • Footer: brand line, social chips, sitemap with Patreon highlighted, one copyright line. Keep page-specific notes with <p class="footer-note"> inside the footer; they are preserved.
  • Newsletter: appears late (after real scrolling), never on the first screen, and remembers dismissal for 30 days.
  • 404 and /patreon/: /404.html is a real HoovyTube page on this skeleton (no redirects); /patreon/ forwards to /products/. Both are owned by the design system.
